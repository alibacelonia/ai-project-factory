# Editorial UI

Use magazine-like pacing, expressive typography, photography, and narrative composition for portfolios and long-form content.

- **Palette:** Light paper `#FBF8F1`, foreground `#211E1A`, primary `#8C2F39`, accent `#B7791F`, surface `#FFFFFF`, border `#D8D0C5`, focus `#005FCC`. Dark ink `#151412`, foreground `#F5F0E7`, surface `#23211E`, primary `#F09AA4`, accent `#E6B96A`.
- **Type:** Characterful serif for display and long-form headings paired with a neutral sans for navigation, metadata, and forms. Use readable measure, drop caps sparingly, and never sacrifice heading order.
- **Surfaces:** Paper-like fields, editorial rules, image-led sections, varied column widths, and minimal shadow. Captions and metadata have consistent placement.
- **Components:** Story cards, pull quotes, project indices, bylines, share tools, forms, and related-content modules all use semantic primitives. Tables remain conventional.
- **Interaction:** Links underline visibly; hover may reveal image caption or subtle crop. Focus is a crisp ring and never hidden by image masks. Disabled controls use muted paper tones while retaining text contrast.
- **Responsive:** Recompose spreads into a single narrative flow; position captions adjacent to their media and avoid isolated pull quotes.
- **Accessibility:** Provide image alternatives, transcript or equivalent for media, sensible reading order, and no decorative text embedded in images.
- **Theme/performance:** Dark mode uses warm ink surfaces and adjusted imagery, not global inversion. Optimize responsive images and fonts, reserve dimensions, limit parallax, and honor reduced motion.
