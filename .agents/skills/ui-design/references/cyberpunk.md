# Cyberpunk

Use a dark technical canvas, disciplined neon signals, sharp geometry, and scan-like details without sacrificing usability.

- **Palette:** Dark default background `#07080D`, foreground `#E8FFF8`, primary `#00F0FF`, secondary `#8B5CF6`, accent `#FF2DAA`, surface `#121522`, border `#34405A`, focus `#F7FF00`. Light alternative background `#EDF7F5`, foreground `#111827`, surface `#FFFFFF`, primary `#006B75`, accent `#A60068`.
- **Type:** Condensed or futuristic display face for headings, monospace metadata, readable sans body. Avoid all-caps paragraphs and overly tracked form labels.
- **Surfaces:** Cut-corner shapes, thin neon edges, dark panels, restrained grid/scan textures, and targeted glow only on active elements.
- **Components:** Angular buttons, labeled inputs, command/status cards, modern tables, accessible dialogs, and alerts with icon and text. Controls remain familiar beneath styling.
- **Interaction:** Hover activates an edge glow; press removes it. Focus uses a stable yellow or white outline, not flicker. Disabled controls stop glowing and retain readable labels. No essential glitch animation.
- **Responsive:** Remove decorative side rails and reduce texture density; preserve conventional mobile navigation and target sizes.
- **Accessibility:** Avoid chromatic vibration and neon body text. Errors and statuses require text/icons. Never flash or rapidly glitch; keep glow away from fine text.
- **Theme/performance:** Dark is preferred; light is a technical print-like alternative. Use CSS borders/gradients, cap shadows, avoid canvas/WebGL for ordinary screens, and eliminate ambient motion under reduced-motion.

Representative preview: CloudOps console with angular navigation, command card, service table, alert banner, and clearly labeled controls.
