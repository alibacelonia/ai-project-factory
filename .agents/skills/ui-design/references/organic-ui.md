# Organic UI

Use asymmetric curves, natural color, tactile illustration, and generous rhythm for wellness and lifestyle experiences.

- **Palette:** Light background `#F4F1E8`, foreground `#263126`, primary `#4D7654`, secondary `#A66A4C`, accent `#D6A73A`, surface `#FFFCF4`, border `#BBC5B5`, focus `#1F5E35`. Dark background `#172019`, foreground `#F2F5EC`, surface `#263129`, primary `#9BC7A1`, accent `#F0C76C`.
- **Type:** Warm humanist sans with an optional soft serif display face; relaxed leading and comfortable measure. Avoid handwritten type for controls.
- **Surfaces:** Uneven but bounded radii, leaf/pebble shapes, subtle paper grain, muted tonal fields, and soft grounded shadows. Content areas remain geometrically predictable.
- **Components:** Rounded cards, warm buttons, conventional labeled forms, timeline or ritual lists, calm alerts, and natural-media empty states. Controls share consistent hit boxes despite visual curves.
- **Interaction:** Hover gently lifts or shifts tone; selected states gain a clear border/check. Focus uses a crisp ring that is not organic or ambiguous. Disabled controls use a desaturated fill plus readable label, not faintness alone.
- **Responsive:** Simplify asymmetric compositions, crop shapes outside content flow, and linearize storytelling without hiding information.
- **Accessibility:** Muted palettes still require AA contrast. Decorative curves cannot clip focus or text. Avoid relying on nature-associated color meanings.
- **Theme/performance:** Dark mode uses deep botanical tones without muddy contrast. Use CSS border radii and optimized SVGs; limit texture files, avoid background parallax, and honor reduced motion.

Representative preview: wellness dashboard with organic hero, daily ritual cards, progress list, accessible check-in form, and gentle status feedback.
